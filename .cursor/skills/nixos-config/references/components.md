# Home Manager component inventory

Every entry imported by `modules/home/default.nix`, in import order. "Config" is how the app is configured: **HM** means a Home Manager `programs.*`/`services.*` module, **file** means a raw dotfile linked with `xdg.configFile`/`home.file`, **dconf** means `dconf.settings`, and **pkg** means a bare `home.packages` entry.
